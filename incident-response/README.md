# Incident Response

The Enterprise SOC Lab includes an incident-response capability designed to demonstrate how a SOC analyst moves from an initial security detection to investigation, containment, evidence collection, recovery, and incident closure.

The incident-response workflow builds on the detection engineering and threat-hunting capabilities already implemented in the lab.

---

## Incident Response Lifecycle

The lab follows the following operational workflow:

```text
Detection
    ↓
Triage

Investigation
